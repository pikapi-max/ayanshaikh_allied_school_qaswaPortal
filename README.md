# Allied School Qaswa Campus Portal

A redesigned, animated and responsive student portal for Allied School Qaswa Campus, Larkana.

## Included
- Light-blue and white professional visual system
- Animated Allied School-inspired crest and floating hero elements
- Responsive navigation and mobile layout
- Scroll reveal animations and reading progress indicator
- GitHub Pages-ready static files

Open `index.html` locally or enable GitHub Pages from **Settings → Pages** using the `main` branch.

> The crest is an editable SVG recreation. Replace the SVG inside `index.html` with the official logo asset if required.
